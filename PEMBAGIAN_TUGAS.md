# Pembagian Tugas Anggota - Projek Akhir TugasKu

Isi nama dan NIM anggota pada kolom yang tersedia, lalu masing-masing mengunggah file bagiannya ke eCampus dan mem-push ke GitHub.

| Anggota | Nama / NIM | Tabel | File yang dikerjakan |
|---|---|---|---|
| 1 | ................ | `users` | `pengguna.php`, `includes/users.php` |
| 2 | ................ | `mata_kuliah` | `matkul.php`, `includes/matkul.php` |
| 3 | ................ | `reminders` | `pengingat.php`, `includes/reminders.php` |
| 4 | ................ | `tasks` + integrasi | `index.php`, `tambah.php`, `status.php`, `hapus.php`, `includes/db.php`, `includes/functions.php`, `includes/header.php`, `includes/footer.php`, `assets/style.css`, `README.md` |

## Alur GitHub
1. Anggota 4 membuat repository dan mem-push proyek lengkap ke branch `main`; anggota lain di-invite sebagai collaborator.
2. Tiap anggota `git clone`, membuat branch `fitur/<nama-tabel>`, commit atas nama sendiri, lalu push dan buat Pull Request.
3. Anggota 4 melakukan merge. Riwayat commit menjadi bukti kontribusi masing-masing.

## Alur eCampus
Setiap anggota mengunggah folder `anggotaN` miliknya dari `upload-per-anggota.zip`, ditambah tautan repository GitHub.
